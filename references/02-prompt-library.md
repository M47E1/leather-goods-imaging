# 可组合的修图提示词

## 组装

一次 = 身份角色 + 不变量 + 局部动作 + 一个机位说明 + 构图背景 + 禁止项 + 成功判据。填完括号，删掉无关模块再执行。不要把历轮失败提示词拼成长咒语。“只去纸、不改角度”不能搭配“标准三分之四”；保留卡内文字不能被清除全部文字覆盖。工具不支持蒙版时，不假装文字就是像素蒙版。

### 模块职责与冲突消解

| 决策 | 唯一归属 | 局部模块不得偷偷改的内容 |
|---|---|---|
| 相机方位、俯仰、透视 | 当前任务选择的一个V模块 | 去包装、补纹理不能自行转正或锁住另已获准的机位变化 |
| 区域内的几何变化 | 明确的L模块和锚点 | 全局“比例不变”应改成保护非目标区，不能否定已批准的局部压缩 |
| 文字 | 当前任务的逐区域文字规则 | 保字区不叠加匿名；增强功能压印不重写字形 |
| 输入与版本 | 当前有效选图和参考角色 | 原拍只供指定证据，不能取代被选中的编辑底图 |
| 范围和次数 | 当前授权 | 选模块不是新增修改或重试许可 |

将模块展开成一份最终提示词后逐项核对，而不是直接把整段库拼接上传：
1. 每个机位、文字区、几何区是否只有一个明确目标？
2. 每个“保持不变”是否误覆盖本轮获准的修改区？按区域重写不变量，不笼统删除保护要求。
3. 动作是否有来源、程度、验收与允许残留？没有必要的动作删去。
4. 真正不能同时满足的用户要求，先指出冲突；不要让模型自行选择。

例如：去包装且改正视＝L01+V1；仅去包装不挪视角＝L01+V0；非托特简单弧顶＝L06，不是L16。功能卡保字用L10，不给该区域再叠加L03。只去包装时，无需上传正常支撑主图或加入任何形态优化。

## 通用实拍基座

```text
这是同一件真实产品的局部照片编辑，不是设计新包或生成相似商品。
第一张是[SKU/颜色/可见面/用户指定版本]，唯一编辑底图。保留本轮未获准改变的初修成果，包括已清理包装、按区域约定的铭牌状态与非目标构图。
其他输入：[逐张角色；无则删去]。只参考明确局部，不恢复旧包装、文字、机位或缺陷。
只允许：[区域和动作]。保持不变：[比例、可见面、面片、口袋、拉链路径与数量、五金款式、带根、颜色等相关不变量]。
保留原皮纹/织纹的尺度、方向、不规则性、自然光泽与缝线张力；不换材质、不加粗颗粒、不磨成蜡/塑料、不镜像复制左右。
背景：[项目约定；纯白目录图要求RGB255，可有适当自然接触阴影及抗锯齿过渡]。白色产品、展示纸、透明膜、高光和阴影不是要抹去的背景。
铭牌：[匿名/保留指定文字/此区不动]。功能文字例外：[明确区域]。禁止新增品牌、字母、图案和装饰。
构图：[画布、批准机位、同款参考占幅]；产品、提手、背带端、拉片、角部完整，不为填框拉伸。
不加新包装带、标签、吊牌细绳、五金、口袋、缝线或支撑片，不把背面改正面。
允许残留：[例外]。验收：[3–5个可观察条件]。其他区域不修。
```

RGB255、1536、保真都须查实际输出。用户接受原样时，不为满足模板再调图。只要求提示词就不调用。

## 视图模块：仅选一个

**V0 原机位：** 相机方位、俯仰、透视、可见面全部沿用目标图；不转正、不加侧深，只处理指定局部。

**V1 平视正/背面：** 保持当前真实[正/背]面，机位接近包身中心、光轴近水平，校正[指定偏斜]；保留侧围厚度与设计不对称，不镜像、不横向拉伸，尤其不改变后袋/前片身份。

**V2 轻俯视：** 水平朝向基本不变，仅略抬机位、轻微下看，使顶部开口/拉链轨道形成窄小可见平面，正面仍主导。不是顶视、图像平移或只多露顶边；不夸大顶部、不缩短包身。

**V3 过侧回转：** 仅向正面小幅回转，减小侧面占比，主要面更充分可见，仍有真实侧深。用[参照/地标]控制，不转另一侧、不换前后、不发明隐藏结构。

**V4 更平更远：** 降低过高机位，光轴更水平，减少近距离广角式前大后小，呈现较远中焦感；不消除真实深度，不改变产品物理尺寸。

**V5 只调占幅：** 只居中、留白与[比例]等比缩放；不改透视/机位/形状、不重绘。[若无重采样：原像素置入更大白画布；若已允许：仅一次等比重采样]。完整配件不可裁。

## 局部模块

### L01 包装纸套/绑带
```text
仅移除[位置]的临时白纸套/塑料袋/包装绑带；按有证据的原连续带面修复遮挡位置。保留真实肩带、扣环、缝线。去后不能再出现白带、透明扎带、黑绑线或替代固定物。机位仅遵守本任务选定的V模块，本动作不增加任何机位要求。
```
遮住复杂真结构时查参照/询问，不任意补。卡窗白纸不自动适用。

### L02 金色细吊牌绳
```text
仅去除[位置]金色细吊牌绳及属于它的残端，局部填补；保留金色拉链、拉片、链条、铆钉、结构缝线和功能文字。不留灰碎片、涂抹块或五金断裂。
```

### L03 铭牌打码
```text
保留金属实体、位置、尺寸、厚度、轮廓和正常反光，只使品牌文字不可辨识，延续无字/匿名状态；不辨认、补写、重描、锐化字母，不换随机字符。此动作不适用于指定保留的RFID压印/功能卡文字。
```

### L04 扶正牌/扣
```text
围绕原固定点/转轴小幅扶正[部件]，使中心轴与指定包体基准一致；不改款式、长宽、轮廓、连接、材质，邻近缝线自然衔接。牌字只遵守该区域已选文字规则，不借扶正补字或删字；扣保留原圆角/翻盖，不变成新方片。
```

### L05 原位上翻短提手
```text
只把原来朝下的同一短提手翻成朝上的自然弧形。两根固定在原横缝的两个原出缝点，不外移、上移或接到包顶。
根部从横缝内部出来，被缝口前唇遮住，不长在外侧皮面，不加贴片、X缝、铆钉或支撑结构。长腿在包顶弧边前方连续延至原出缝点。
保持原带宽、厚度、实际长度，只改姿态；旧下垂短环及残条全部移除，不能两套提手并存。中间向下背带是另一段结构，其起点/折角不挪。
[本轮明确允许才追加：去白套、补全截断长背带、居中控制大小。]
```

### L06 原设计简单弧形提手
```text
按指定同款参照，将[获准的现有提手]修成简单连续弧顶，根部、长度、带宽、厚度、连接方式和包身比例符合原设计。不同视图保留合理投影，不新增第二套提手，机位仅由本任务选定的V模块决定。适用于有该结构且明确要求此动作的背包或其他品类，不以是否托特决定能否执行；本图明确不动提手时不执行。
```

### L07 五层连接
```text
此款已确认五层。五条连续带段按指定端点连接，带宽/材质保留。红示意在前遮住蓝示意在后，后段不穿透，标线颜色不进入成品。允许简化隐藏段，不添第六层、短碎条、新扎带，不改包身。
```

### L08 断带延伸
```text
从截断的[背带/腕带]截面沿原方向自然延伸，原宽度、材质、缝线与已知端部设计不变；原起点、扣环、折角不动。不因此改提手长度、不造新扣件。完整放入画布，不能再次截断。
```

### L09 卡窗/展开内页
```text
白色部分是插卡展示纸，保留。沿用本任务V模块选定的[正面平视/允许的斜视]；真实内框、纸片、外开口为完整长方形/正方形。正视时对应边横平竖直、四角直角；斜视保留一致透视，不强迫屏幕直角。
保留卡槽数量、透明窗膜、包边厚度、折叠连接和许可的一道中间折痕，只除指定条码、斑块、误生成内层相框。纸纯白或按本图许可接近纯白，可保留光照，不留两块异色补丁；不是发光白洞。
```

### L10 卡内保字并旋平
```text
现有卡内文字、字形、布局全部保留，不重写、不打码、不替换白纸。仅原位略旋至水平，校正下端指定横线与底边不平行。保护卡槽、包边、材质，不移动卡到新位置。
```

### L11 原款拉片
```text
参照同款确切局部恢复原拉片，保持连接环、铰接、长宽厚度与孔形；暗反光不自动解释为镂空。形态为[证实的弧面/端部粗细等]，自然受重力下垂，不另换通用平直方孔款。去细绳不能擦掉拉片。
```

### L12 局部凹陷/皱褶
```text
只减弱[右侧/左下/标区]的大凹陷与褶皱至[轻微/一半/指定程度]，恢复自然支撑；保留小皮纹、缝线张力、未指定部分和允许的自然不规则，不磨成平板、不强化颗粒、不镜像。
```

### L13 下段压缩（经授权脚本/受控编辑）
```text
基线为[确切版本]。固定上部保护区域、横拉链及整个悬垂拉片、包宽；只将[下段两地标]高度H变为H×r，包底上收，侧缝/底圆角连续。
不整包缩小、加宽或加高上半伪装压缩。保留现有浅皱，阴影合理随底平移。r只属于本图。验收地标距离/宽度/上部像素保护，以及无接合台阶、拉片不变短。
```

### L14 功能压印对比度
```text
仅用现有明暗轻微提升[RFID压印]对比度，原字形/位置/皮面/压印感不变；不补字、不变白色印刷、不全图锐化或添颗粒。原图无信息时说明限制，不伪造字形。
```

### L15 白底/边缘/阴影
```text
只处理确定外部背景：无阴影处RGB255，包括原照片矩形内部和确定是真空隙的带孔。保护白皮、卡纸、窗膜、高光、抗锯齿和自然阴影，不按全图亮度阈值抹白。
保留或依授权补轻柔接触阴影，不硬描边、不漂浮、不重影、不灰框、不黑边或白晕；不重绘商品。
```

### L16 托特提手自然立起
```text
仅在本图已确认需要立起托特提手时，将原提手调整为正常受力的自然弧形姿态，实际长度、带宽、带根与原连接不变；两根提手按当前视角产生合理遮挡，不强迫侧视同时完整展开。不是增加包高、加长提手或改造非托特；明确不动提手的图不执行。
```
验收：同款提手比例和原固定点不变，无双份旧环、硬折或截顶。普通弧顶修复用L06，原缝翻转同一短环用L05，不重复叠加三种动作。

### L17 抠多了的缺边/面片恢复
```text
目标为[当前候选]，第二张[同款同色原拍/初修图]仅供[缺失边缘区域]的真实结构。沿[两个以上对应地标]对齐局部投影，只恢复被误抠掉的[圆角/包边/面片/缝线]；边缘厚度、纹理尺度和邻域光照连续。保留目标已通过机位、匿名铭牌、去包装及其余轮廓，不把整块旧背景或旧塌陷贴回来。
```
验收：缺失轮廓与可见源证据相符、连接无台阶/白晕/重复缝线；不能用镜像补不同结构的一侧。源图没有该部位或视角无法可靠对应时，停止猜补，申请同款局部原拍。

### L18 去锯齿与轻度模糊改善
```text
只处理[指定边界/轻度模糊局部]，以当前有效底图及[同款真实清晰参照，仅在需要时]为依据。边缘做保守抗锯齿和自然过渡；能恢复的现有细节仅适度改善，不缩窄包边，不改轮廓，不凭空生成毛孔、针脚或文字。皮纹/织纹尺度和未指定区域保持原样，不以全图锐化制造清晰感。
```
验收：100%查看无阶梯、白晕、黑边、重影和锐化颗粒；实际展示尺寸不显塑料或过锐。若源细节已经丢失，不承诺“无损变高清”；转用真实清晰原拍或保留限制。

### L19 恢复少量自然浅皱
```text
第一张[最新指定候选]是唯一目标，第二张[初始同款同色实拍]仅作为浅皱的方向、尺度和幅度参照。只在[区域]恢复[少量、低幅、比初始弱]的自然受力浅皱；已批准的上部形状、宽度、机位和局部压缩结果保持。禁止恢复初始图的大塌陷、旧比例、包装、标字；不把原皱机械复制成重复沟槽，不重新生成皮纹。
```
验收：略有原材质的自然张力，不蜡化、不新增大折痕；与几何压缩组合时，写清当前几何基线与最终地标，不能由皱纹参照决定包高。没有可信浅皱参照时先说明，不把生成浅皱称为原实拍细节。

### L20 产品观感轻微对比度
```text
只对[产品区/指定面片]适度调整现有明暗，让[原有缝线/面片层次]稍更清楚。保护黑皮暗部细节、原色相与饱和度、中间调、金属反射和已合格白底；不全图拉黑、不增粗颗粒、不用锐化代替对比度，不恢复匿名铭牌的文字。程度以[同款参照/用户认可的轻微变化]为限。
```
验收：前后同尺度看得到适度变化，暗部未堵、浅色未剪白、颜色未改；单枚功能压印增强用L14，不把本模块作用到全部字区。

### L21 局部反光/曝光纠正
```text
仅减弱[位置]遮挡细节的异常反光，以[源图可恢复信息/同款同色局部曝光参照]为依据，保留真实皮面或金属的正常光泽。局部明暗自然接续，不涂成哑光灰斑、不改变产品颜色、不把蓝色款改成黑色款，也不将亮部、白皮、白纸一概当成过曝。其余光照和纹理不改。
```
验收：反光减弱且原有结构更可辨，无平涂补丁、过暗边界或新纹理。源像素已完全剪白且无参照时，不能宣称恢复真实细节；提出补拍/换曝光，不靠压暗纯白伪造。

### L22 非卡窗局部几何与单侧高度/缝线校正
```text
仅修[区域]的[不自然弯曲/单侧偏低/横缝偏斜]。锁定[固定锚点与保护区]，沿[方向]移动[目标边/地标]，幅度为[明确距离，或相对当前偏差只修约一半]；对照基准为[原水平结构/已确认同款形态]。保持另一侧、包宽、五金连接、口袋数量和原纹理；侧缝、横缝与底圆角连续。不镜像、不强制真实设计对称，不用整包旋转或缩放代替局部补偿。
```
验收：分别量原/新地标偏差、整体宽高与保护区；“修一半”是异常偏差减半，不是把某一侧高度缩成一半。先区分透视与真实塌陷；若问题属于机位，用V模块，不把本模块当镜头转换。精确脚本变形仍需对应授权。

### L23 指定吊牌片/指定带段移除
```text
仅移除标注中的[可拆椭圆吊牌片/明确指定的多余带环或带段]，对象边界为[端点/框/连通区域]。保留[列明的真实肩带、扣环、铭牌、拉片与承力连接]；遮挡后区域仅按可见邻域和真实参照补全。不扩大为所有标签/椭圆五金/整条肩带删除，不生成新的固定物。
```
验收：删除对象与标注完全对应，无残端、悬空带、断开的真实承力连接。若对象只是包装用L01、仅细吊牌绳用L02；无法确认指定段与真实结构的关系时先核对，不能以“类似”擅删。

### L24 点状缺陷/铆钉点小范围处理
```text
只对[明确坐标或标注]的[误生成点/用户指定铆钉点/污斑]做[遮盖打码/邻域修补]，影响范围不超过该点及必要过渡。保留附近皮纹、真实结构铆钉、缝线和反光；不重新生成整包，不把点状修补扩大到所有五金或文字。其余已通过区域不动。
```
验收：点状目标达到指定不可辨/移除程度，邻域没有涂抹块和纹理断层。只有目标明确时才处理；不能把源图真实连接件当成瑕疵。若非生成像素处理更合适，按工具规则及用户授权选择，不自动执行脚本。

### L25 正常支撑与内部体积恢复
```text
第一张[指定候选]为唯一目标；第二张[同款认可主图]仅作正常支撑状态参照，原拍[如需要]仅供材料与结构。仅修[指定空瘪面片/侧墙/包底塌陷]，使肩、正面、侧围、底部成为一致的自然立体形态，保留当前选定视角和真实厚度关系。不照抄主图二维轮廓，不鼓成气球或硬壳，不换皮纹、加夹层、改尺寸或镜像。
```
验收：不仅外轮廓顺，面片内部也不洞状塌陷；侧墙/拉链/口袋投影、角部与底部接触一致，小皱仍自然。没有可核实的正常形态时先说明；若只需减一处皱用L12，不能自行升级为全包体积重建。

## 完整示范：只去包装、保持机位

```text
第一张为指定初修版包背面，唯一编辑目标。只去中央束在背带上的白色包装纸套，沿原连续带面修复，不生成任何替代扎带。
保持原机位、俯仰、可见面、包身宽高、提手长度、带根与折角。只修四周已指明的轻微异常凹凸，不正面化、不转成三分之四、不镜像。
原材质、颜色、五金、拉链、匿名铭牌不变。背景纯白RGB255，可有自然阴影；完整居中，不裁带端。验收：无纸套/新扎带、角度不变、原带连续、边缘修顺而包型不变。
```

提示词不是越长越好：只剩白底或打码，就删掉所有视角、提手和形态优化措辞，避免重新破坏已通过内容。
