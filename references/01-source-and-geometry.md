# 参考、拍摄与几何判断

## 输入角色

| 角色 | 可以决定 | 不应默认决定 |
|---|---|---|
| 唯一编辑底图 | 本次可见内容、已完成修图 | 错误生成结构不是实物真值 |
| 同款同色原拍 | 真实皮纹、织纹、面片、五金、自然光泽 | 不恢复已删除包装、匿名文字、旧机位 |
| 认可主图 | 正常支撑时的肩、侧墙、底部、体积 | 不把三分之四二维轮廓强压到正侧背视图 |
| 用户标注 | 锚点、线序、范围、目标轮廓 | 标线不是实物颜色，不授权其他改动 |
| 其他SKU例图 | 用户指定的连接逻辑 | 不移植包体、皮纹、颜色、五金款式 |
| 其他候选 | 用户点名采用的局部效果 | 不把生成皮纹当原材质，不替代最新底图 |

记录角色、路径、SHA256、来源和限制；本地图片先查看再编辑。只用原图时不夹带错误候选，在最新候选上修时不偷偷回退原拍。标注照片可能包含已被否定的结构，必要时让用户在正确底图上重画；“只参考红线”不能保证模型不复制整图。

## 构图记录

分别记录包身框B（不含高提手/拖带）、完整产品框T（含配件）、阴影S以及关键锚点（根部、横拉链、侧缝、包底、卡窗四角）。不要只用全图非白像素框决定主体大小。

同款对照先匹配包身高度/确认实体尺寸，再看轮廓和纹理尺度。侧面不能为了填满方图放大到比正面高很多，长背带也不能把包身挤得过小。占幅、留白、角度没有确认数值就不编硬标准。

主图、正面、背面、侧面、内页、细节图分别传达不同事实。颜色、开合状态、独特后袋或另一面卡槽不同，不是重复图。跨SKU不得合并媒体身份。

## 视角、透视、占幅、形变

| 问题 | 操作 | 不是 |
|---|---|---|
| 过侧 | 向正面小幅回转 | 横向压扁、换前后面 |
| 过俯 | 降机位、光轴更水平 | 把图往下移 |
| 轻俯 | 略抬机位，露窄小顶部平面 | 旋转画布、多画一条顶边 |
| 近距离广角感 | 减少近大远小、采用更远中焦感关系 | 放大顶部、把远侧拉宽 |
| 仅主体过大 | 调占幅、居中和留白 | 顺便改机位 |
| 局部太长 | 锁锚点与宽度，局部纵向变形 | 整包缩小或横向加宽 |
| 左右不齐 | 判断投影/设计/塌陷，分别调整 | 镜像半包、移动真实配件 |

透视主要由相机和物体相对位置决定。“中焦感”是摄影意图，不是单图可测出的焦距。不要伪称准确相机距离/角度。数字只在有证据且经确认时使用，不把例图10–15度变成全产品标准。

大转角会显露原图没有的表面。实物图优先匹配视角原拍或补拍；一句“细节不变”不能恢复不可见缝线/皮纹。无证据时保留原视角或说明概念补全，不能冒充保真实拍。

## 支撑和褶皱

正常支撑不等于鼓成气球或硬壳。先看包顶、两肩、正面、侧围、底接触是否为同一立体形体，再看侧缝、拉链、口袋投影与角部衔接。轮廓顺了但内部仍塌陷，不合格。

自然皮纹、缝线压缩、张力小皱保留；用户点名的大凹陷/运输折痕局部减弱；生成的规则沟槽、蜡化光滑和重复噪点是退化。“只修右边/修一半/少一点凹凸”是范围限制，不扩展全包。恢复浅皱时原拍只作浅皱参照，不带回旧机位、包装和塌陷。

## 带的连接拓扑

每条带先明确起点、终点、折角、前后层序、穿环扣位置、遮挡和连续段。一条折带可以有很多可见段，不能数线即数带。

- 提手和下垂背带可能邻接，但不一定同一条；先看缝口和折转。
- 从缝内出的带根被缝口前唇遮挡，不是贴在皮面上的外植片。
- 翻起同一短提手是姿态变换，不挪根、不改长宽、不加X片/铆钉。
- 上翻后去掉旧下垂环及残条，不留两套提手。
- 补断带只按原方向、宽度、已知端部自然延伸；不加未知扣件。
- 五层只适用于已确认五层的那款；前后遮挡、连续带边比凑出五根线重要。
- 红前蓝后是示意，后段应被遮住，不能穿透前段；红蓝色不进入成图。

## 补拍任务单

准确说明缺的是连接缝、拉片侧面、同色背面、皮纹或卡窗，不笼统索要更多高清照。同款同色、原连接不改、原文件保留。

稳定相机，目标面中心附近的机位，避免贴近广角；柔和大面积光显示真实表面，同时保留正常反射。黑皮检查暗部缝线，白皮检查边界/高光不截断。按实际结构补正侧背、展开内页、关键五金，不强迫每款相同张数。

颜色要求严格时记录白平衡/色卡/显示环境；未测量不承诺色差数值。这是取证方法，不是相机、镜头、灯具购买建议。
