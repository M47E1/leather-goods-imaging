# 材质与部件专业标准

## 1. 实物身份优先级

质量不是单一“好看”。按身份、结构、材质、授权形态、摄影表现、技术交付分别判断。不得为了白底、对称或满版而改变产品。材料名称由已确认商品事实决定，不能看图就宣称头层、全粒面、真皮等级、厚度、植鞣或防水等属性。

| 材料/部分 | 应保留 | 常见生成退化 |
|---|---|---|
| 有自然颗粒的皮面 | 非重复颗粒、方向和相对尺度、压缩、自然反光 | 小颗粒变粗砾石、均匀噪声、镜像纹理 |
| 细纹/柔软皮面 | 柔和不规则皱纹、边缘张力、细微明暗 | 磨成蜡、硬板、平滑塑料 |
| 拼接皮面 | 原片数量、格缝、颜色差异及原拼法 | 无中生有加格、缝线错位、改成整片 |
| PU/合成表面 | 实际表层纹路和光泽，已确认材料名 | “升级”为牛皮、添真皮毛孔 |
| 织物/尼龙类 | 真实细织纹、低幅软皱与弯折行为 | 改成皮革、绒面、粗麻布或规则沟纹 |
| 内衬 | 原层次、口袋/卡槽、接缝、光照 | 变成白背景、抹掉功能结构 |
| 金属 | 原形状、反射、厚度、边缘和连接 | 新造孔、熔化、消失、悬空或镀色改变 |

同款不同颜色也不能随便移植纹理。原材质看不清，就明确未核实，不用“超清细节”生成替代证据。新拍摄概念可描述材料，但不能据此确认实物属性。

## 2. 反光、曝光、对比度

亮不等于过曝。先排除白皮、背景、金属、拉链齿与正常反光。只有遮住本来可恢复细节的局部高光才是纠正对象。

有源信息时做受控局部明暗调整，保护颜色、邻域中间调、皮纹和明暗过渡；不为消反光改成哑光。不用全局拉暗制造灰补丁，不用锐化创造细节。全部通道已丢失细节时，找同视角原拍/其他曝光或保留限制；压暗纯白不等于恢复纹理。

“提高对比度”应说明对象：整包观感还是某枚RFID压印。轻微增强不能把黑皮暗部压死，不能使压印变白色印刷。未校准的亮度/面积阈值只作检查标记，不自动触发修图。

## 3. 白色语义分割

| 白色区域 | 处理逻辑 |
|---|---|
| 真实外部背景 | 项目要求纯白时设RGB255；包括原照片矩形内部 |
| 阴影、边缘抗锯齿 | 可保留自然渐变，不要求每像素白 |
| 白皮、真实白肩带、里衬 | 是产品，不能抹除或变透明 |
| 包装纸套、纸袋、绑包带 | 确认临时包装且获准才删除；去后不生成替代绑带 |
| 卡窗展示纸 | 通常用于展示可插卡，按要求保留和校正几何 |
| 功能说明卡 | 可能必须保字，不能套铭牌匿名规则 |
| PVC窗膜、金属反射 | 保留透明度/反射关系，不能当洞 |
| 真正提手孔、带间空隙 | 逐区确认后按背景处理；内部白框不当然是空隙 |

白底验收不能只采四角或新增白边。原1254近白图放入1536白画布后，里面的灰白矩形仍然存在；补边像素通过不等于全背景通过。也不能全图阈值变白，因为白商品会被吃掉。

## 4. 文字是按功能分类，不是全部删除

- 客户要求匿名的品牌铭牌：保留金属实体，只抑制文字。初修无字，禁止从原拍恢复。
- 要扶正的铭牌：只调牌位/小角度，文字仍按该牌规则。
- 明确保留的RFID等功能压印：保留字形和位置；若只增强对比度，不重描、不替换拼写。
- 指定保留的插卡说明：旋卡不能改字。匿名通则不适用。
- 被点名移除的条码、污斑：只删对应对象，不把整张展示纸删掉。
- 用户说一两个字的遗漏可接受：是本批次容忍，不是以后可以生成新字。

用户口述“IFID”等拼写不构成重写产品字符的指令。先看真实图；不自动更正印刷、也不凭模型猜字。看不清写“无法核实”，不要捏造可读文本。

## 5. 硬件和接缝

拉链需要分别检查链轨、齿、布边、滑块、拉片和连接环。拉片自然下垂不等于款式正确。应保留原弧面、长宽、两端粗细、孔洞及铰接；反光暗部不能被解释成方孔。某同款证实的“中间细、两头粗、下头更粗”只适用该款，不是所有拉片标准。

修搭扣先找固定点、转轴、中央线和包底参考。轻微歪斜不等于换款。清细绳时必须检查旁边拉片、压印是否被擦掉，灰碎片/涂抹边缘即使蒙版外像素不变也要判失败。

缝线是结构证据：数量、起止、双线间距、面片连接、包边厚度保留。结构修正不授权新增X片、铆钉或工艺细节。所有可制造性判断都应区分照片可见和实际需实物确认。

## 6. 品类特征与禁套模板

| 品类 | 重点 | 禁止误套 |
|---|---|---|
| 背包 | 提手/肩带分离、背面口袋、带根/调节扣/底环 | 背面改正面、提手长在皮面、背带与提手并成一条 |
| 托特 | 同款提手长度、自然立起、包口与侧深 | 非托特自动拉起、侧视强撑双提手 |
| 肩包/斜挎 | 带环、折带层序、挂扣、前后袋 | 加不真实包带、镜像五金 |
| 腰包 | 侧袋体积、腰带穿扣、接缝与底接触 | 只顺轮廓而主体塌陷、扣件凭空填黑 |
| 钱包 | 原厚度、边缘体积、拉链路径、翻盖/搭扣 | 拍成纸片、为了体积夸张鼓起 |
| 卡夹/展开内页 | 卡槽数量、窗口真实矩形、展示纸、折线 | 多加相框、删白纸、斜视强行屏幕直角 |
| 织物小包 | 细织纹、软皱、接缝 | 自动皮革化、消灭全部褶皱 |
| 皮带 | 带头、带孔、扣具、真实正反面 | 使用包袋的口袋、拉链、内衬模块 |

品类名仅用于选择观察项；真实图和用户说明优先，不因目录标签推断结构。
