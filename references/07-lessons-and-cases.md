# 匿名失败案例与有效纠正

这些案例保留方法，不保留客户图片、SKU、网站状态、调用原文或本地路径。它们不是待执行队列，也不是生成效果保证。

| 失败现象 | 判断与纠正 | 验收与模块 |
|---|---|---|
| 修图后铭牌长出新字 | 先核对编辑底图和参考角色；不能仅凭结果断言传错图 | L03；无可读品牌字，实体牌不变，功能字不误删 |
| 背景近白、白框内仍灰 | 外围补白不是原照片背景归一，四角检查不够 | L15；检查真实背景、孔隙，保护白产品与阴影 |
| 去纸套后生出黑扎带 | 对象被模型理解为需要替代固定 | L01；明确禁止任何替代固定物 |
| 去包装时挪了视角 | 局部动作夹带了别图的机位目标 | V模块独占机位；只去纸用V0，获准正视用V1 |
| 背包弧形提手被托特限制跳过 | 品类条件与动作条件混淆 | L06不排除有该结构的非托特；L16仅托特立提手 |
| 提手根部搬到包顶、贴皮面、加X片 | “翻上来”被理解成新设计 | L05；两原出缝点不动，根部被缝口前唇遮挡 |
| 上翻后仍留旧下环 | 生成了新姿态却没清除原姿态 | 追踪同一短提手，旧环/残条清除，背带不误删 |
| 五层带混乱或新增第六层 | 可见段数被误当成独立带数 | L07；按端点、折角和前后遮挡追踪连续关系 |
| 内页只变白、边仍歪 | 颜色任务代替了内外几何任务 | L09；纸/内框/外开口同时按批准机位校正 |
| 斜视卡窗被强修成屏幕直角 | 把实体矩形与其投影混为一谈 | 正视才要求屏幕横平竖直，斜视保持一致透视 |
| 功能卡文字或RFID被匿名通则清除 | 没有按区域区分文字用途 | L10/L14与L03分区域，禁止全图删字 |
| 拉片恢复成通用方孔款 | 暗反光被错误解释成镂空 | L11；用真实同款局部确认形状和连接，自然下垂不等于款式正确 |
| 清金线顺手删了拉片/功能压印 | 修改区污染相邻真实部件 | L02；完整硬件保护，局部无灰碎片/擦痕 |
| 模糊图生成粗皮纹 | “超清、奢华质感”被当材质再设计 | L18；保守修边，无法恢复的信息不以新纹理冒充 |
| 去皱后变塑料或硬板 | 把所有细微不规则都当缺陷 | L12减大皱；L19按真实参照恢复小皱，保缝线张力 |
| 轮廓平滑但内部仍塌 | 只做边缘美化、没核对整体形态 | L25；正常支撑主图只供形态，肩/侧墙/底部共同验收 |
| 下段压缩不足、改成整包缩小 | 相对比例与构图占幅混淆 | L13与V5分开；地标距离可测，保护上部和整枚拉片 |
| 轻俯视只多画一条顶边 | 相机变换被替代成2D补线 | V2；顶部是真实窄小可见面，投影关系一致 |
| 包装清理误抠掉角部 | 将产品边缘当背景 | L17；同款原图仅恢复确定缺边，不想象补全 |
| 少量右侧补高变成全包镜像 | “更对称”覆盖了限量修复 | L22；修异常偏差，不抹掉真实设计不对称 |
| 点状微修重绘了整包 | 局部动作失去区域和工具边界 | L24；授权小范围处理，其他通过区域不动 |
| 产品颜色被当反光改掉 | 未先确认该款存在不同颜色 | L21；同色证据优先，调曝光不换颜色 |
| 用户选中较早候选却用了最新文件 | 用mtime/版本号代替用户决定 | 选图依据绑定确切哈希；技术失败可被用户明确接受为例外 |
| 次数用完后换词继续调用 | 把一次新提示词当新授权 | 每轮累计，未知结果先核查，不能无限重试 |
| 内容通过被报告成已上线 | 质量、选择、发布状态混用 | 分别记录，读回实际媒体与普通前端页面 |
| API已更新但悬停图仍旧 | 前端派生/缓存引用未闭合 | 发布验收覆盖商品页、目录、悬停；旧引用消除后才按授权删旧图 |
| 相似图/旧ZIP直接删除 | 相似并非重复，压缩包可能含唯一原片 | 哈希、来源、独特信息与引用一起核对；原片单独保护 |
| 图像索引不变却颜色变了 | P模式只比较调色板索引产生假通过 | 探针v2比较RGBA8与渲染元数据；脚本通过仍不是视觉合格 |

## 三个不能被短口号替代的判断

### 原位翻提手

输入必须是用户选定的正确底图。原拍/标注分别提供真实连接和目标弧线，不把错误候选一起惯例上传。“根部不动”还需说明缝内出带及遮挡；“翻上”还需说明移除原下垂环。只有位置、连接和旧姿态都对，才是同一提手姿态变化。

### 下段压缩与浅皱

最新候选决定上部、宽度和当前机位；初始图只提供低幅浅皱。先用地标定义H和本图r，验实际拉链到底部高度，不以整包变小冒充目标。悬垂五金跨入压缩区时需保护整枚拉片，并再次证明剩余变形仍达到目标。用户未准脚本，不因模型反复失败就改用脚本。

### 上线与单一现用版本

工作项数量、被选视图数量与唯一线上媒体数量可能不同。只留一份指每个有效媒体/视图一个权威版本，不是每款删到只剩主图。未确认原片保存、线上引用和用户删除范围前，不能按名字含“旧/失败/备份”删除。历史记录保留事实，不作为现行修图指令。

## 定型后返修：原像素也需要边界与角色

这些是局部返修的匿名教训，不是所有产品必须执行的新动作。具体路线见[定型后恢复原拍材质](12-original-material-restoration.md)。

| 已观察到的失败 | 纠正与复验 |
|---|---|
| 后续恢复材质，又改变已认可轮廓或提手 | 锁定定型底图，只进入获准皮片内部；外轮廓、完整提手及固定点分别保护 |
| 原拍袋底/牌块贴回后出现重复层与硬贴片 | 供体只提供对应材料，不搬运包含五金、滚边及阴影的矩形块；核对层归属和边界接续 |
| 铭牌匿名后成均匀灰面，皮面降亮让拉片一起变暗 | 皮面与金属分区；保留实体反射及原表面工艺，不能用磨砂填色替代匿名 |
| 已用原拍像素，皮纹仍被拉长或贴成规则纹 | 同面配准，检查方向、尺度与局部形变；原像素来源不是视觉通过证明 |
| 用侧前面参考或邻近皮片冒称恢复背面隐藏纹理 | 按可见证据限定来源，邻近像素修补如实标注；保留可信底图或说明缺项 |
| 提示词夹带加长拉链、包带或重做圆角 | 每个动作追溯要求；校正方向、增强反光与改变长度分别判断，未要求不执行 |
| 大量“中间文件”与当前交付混放 | 先绑定当前选择与原片，精确清理再生投影；保留调用、裁定与发布证据，不按扩展名整树删除 |
