# 第一性原理：整套商业图检查、修复与对抗验收

本章是**通用判断方法**，不是新修图授权，也不是自动视觉检测器。先用[SKU工作法](10-sku-commercial-workflow.md)锁定全套资产和本轮范围；项目允许的文字、画布尺寸、阴影例外、重试次数从项目配置和最新单图决定读取。历史缺陷用于防漏，不自动重开已接受版本。

## 1. 五个原则，先于任何提示词

1. **产品事实不变。** 商品身份、材料、真实颜色、面片/口袋数量、连接与五金是事实；不以“更好看”为由改款。原拍有瑕疵不等于所有形态都不可校正，但无证据的新表面不能宣称为真实恢复。
2. **形态与呈现分开。** 画布、包体长宽比、包身占幅、重心、相机透视、受力形变是不同变量。改了其中一个，不能宣称其他变量也解决。
3. **整套一致，不是逐图同化。** 统一同色材料的表现、相近视图的主体尺度、构图和摄影语言；保留正/背/侧/展开/细节的用途、真实不同色款和合理透视。主图只提供已合格的参照项，不享有免检资格。
4. **最小有效改变。** 能以补边、缩放、调色解决就不重绘；需要局部形变也不默认整包生成。脚本、原像素和生成都只是方法，均可能失败，均须检查改变区及其边界。
5. **改动有效且无倒退。** 只有“指定缺陷确实改善、事实和非目标部分未破坏、技术合格、版本可追溯”同时成立，才能交付候选。用户接受、选用与上线还需各自的证据，不能互相代替。

将修复视为有约束的局部优化：**先满足身份和保护项，再消除指定缺陷，最后协调呈现。** 不能以综合分数抵消换皮纹、缺部件、错版本等硬失败；也不能为追求几何零误差把真软包修成硬盒。

## 2. 先辨认对象，再量它

每张图至少分清下列对象；不要求每次新做一套精细蒙版，只对本轮需要测量/修改的对象标定。

| 对象 | 用途 | 常见误区 |
|---|---|---|
| 包体 B | 测主体高度、宽度、占幅和重心 | 长肩带、拉片、圆环把包体框撑大，造成“实际包身很小却测量正常” |
| 完整产品 T | 检查部件完整、留白、是否裁切 | 从测量中排除带子不等于可以删带子 |
| 外轮廓 O | 顶/底/左右边及四角 | 只看外接矩形，不看中段鼓包、塌陷与下角 |
| 内部结构 I | 前袋、翻盖、卡窗、层间边、横竖缝、拉链 | 外框直了，内框仍歪；把旁边明暗分界误认作缝线 |
| 刚性/语义部件 H | 铭牌、扣具、拉头、口金、文字、卡纸 | 随软皮一起扭曲，字形变形但仍被判“文字保留” |
| 材料区域 M | 同色、同面、同尺度的皮纹/织纹与光泽 | 用白底面积或金属反射参与全图颜色平均 |
| 阴影 S / 外部背景 G | 落点、衰减、纯白、边缘过渡 | 把阴影全部抹白；把卡窗白纸、白皮、高光当背景 |

原图、当前选用、待修底图、参考图、候选图是不同角色。截图上的红线是**目标形态的说明**，不是新的商品像素；在高清底图上以真实结构地标转译，不把截图缩放误差、手画抖动或红线本身写进成品。

## 3. 四种观察尺度，固定检查顺序

1. **整套同画布并排。** 先显示实际文件，不先按主体自动裁切放大。看包体占幅、上下左右留白、同色皮面、光泽、视图是否重复。再开主体等尺度局部对照供材质检查；两种对照须有标签，不能混淆。
2. **单图全景。** 按“外框→内部框/前袋→缝线/拉链→五金/文字→带路→背景/阴影”扫完，不只盯用户点名位置。先确认机位，再决定哪些边应水平/垂直。
3. **原文件100%。** 核皮纹、缝针、齿列、滚边厚度、边缘抗锯齿、文字字形、蒙版接缝和接触阴影。200%仅辅助定位，不能把显示插值当原图瑕疵，也不能只交局部裁图证明整张通过。
4. **实际展示大小。** 看暗部是否读得清、包是否太小、是否悬浮、相册切换是否跳大小/颜色。正式上线还须核对实际页面引用的文件；本地预览不能证明线上已替换。

缺原文件、对应参照或关键部位不可辨时，该检测项写“证据不足”，不是整张自动合格，也不是凭空判坏。

## 4. 检测清单：位置、判错依据、动作、复验

### 4.1 尺度、比例与居中

- 分别报告实际 `W×H`、画布比例、B的高/宽/面积感、完整T留白及视觉中心。**1:1只约束画布**，不保证包身等大、包形正确、阴影自然。
- 同SKU同类视图以已认可主图/对应视图的包体为基准；细长侧面、展开内页、细节图不可机械匹配同一面积。必要时同类钱包跨SKU比较呈现，不把不同实物尺寸改成相同产品比例。
- 中心以包体主面与整体视觉重量判断，不仅取整个T的外接框中心；排除垂下拉片、长带的干扰，但检查完整入画。几何重心/像素面积只是辅助，反光和黑暗会干扰自动分割。
- 等比放大、竖向加高、横向加宽、局部压高必须分开。每次写明**基线文件、区域、百分比、固定点**：整体等比 `w'=rw,h'=rh`；仅加高 `h'=rh,w'=w`；仅加宽反之。用户说“再加5%”时绑定刚确认的版本；不得误用原始版本或无意叠加多次。
- 局部压缩（例如主要缩拉链上方）不能用整包缩小替代；硬件/字区不得随软皮压扁。变形和组合裁切之后只做一次必要的最终重采样，避免迭代损失。
- 复验：数值之外仍同画布并排，检查上下偏高/偏低、主辅大小、比例失真及影子是否跟随。只加白边不解决原来包体过小。

有可靠包体标定时，可记录归一化量 `包体高/画布高`、`包体宽/画布宽`、`包体像素面积/画布面积`、`包体中心相对画布中心的水平/垂直偏移`，便于不同像素尺寸比较。说明标定是人工框、人工蒙版还是自动分割；粗框面积不冒称精确包体面积。遮挡、细长侧面和展开图标注不适用项，不能统一以面积排名判断大小。

若要扩展自动初筛，先用用户已接受与已拒绝的**同类别、同用途、可比视角**样例校准区间，单列误报/漏报，给不确定项人工复核。可脚本硬验的尺寸/文件身份，与需要视觉判断的形状/材质/风格分开；本Skill不因写了公式就宣称已有可靠分割、自动畸变识别或零漏检能力。

### 4.2 横平竖直、内外平行与对称

**适用条件：** 已指定正视、该处设计本应直、参考有依据。三分之四图的透视收敛、圆弧口、梯形设计、柔软侧围和用户已接受的微小自然不平，不以“不是矩形”自动判错。

| 检查位置 | 应查全段，不只端点 | 修复与复验 |
|---|---|---|
| 上沿、下沿 | 左右高差、中段塌陷/拱起、波浪、层间错位 | 校正该条实物边；正视的直段应水平，中段也平，不只旋平两个角 |
| 左右侧边 | 斜率、中段鼓出、单侧变短、上宽下窄、被捏扁后横向摊宽 | 扶正对应边及必要相邻面片；不以整包压窄掩盖一侧突起 |
| 翻盖/前袋/内框 | 内外方向、边距、前后层错向、某侧过低 | 分层定位；外框、内框各自查，前袋不能“外框修完顺带默认通过” |
| 横竖缝/沟槽 | 起止点、中段弯折、交叉点偏移、局部断线 | 明确是针脚线、滚边筋还是光照边；按目标线修，保留针脚和真实交叉关系 |
| 四个圆角 | 左右不合理差异、扁角/钩角/尖点、下角缺高度 | 保留原应有圆角半径和自然厚度，直段到圆弧顺接，不削成尖方盒 |
| 打开式卡包 | 左右开合角、可见面宽度、内框相对外框 | 获准对称正视时校准左右开合关系和内外平行；不可复制同一半，铰轴和卡槽数不变 |
| 拉链周边 | 齿列、上条、下布带、突出顶端/侧端 | 按指定层和数数方向定位；“布带胀开”用几何收拢，不用压暗浅色伪装；齿列、拉头完整 |

**可测但非自动判分：** 对目标直段采多个真实边缘地标，记录方向角、最大偏离直线量（相对包体高/宽），以及沿程内外边距。水平看各点的y偏差，垂直看x偏差；仅做两点连线或最小二乘平均斜率会漏掉中段波浪。圆角另查，不强纳入直线拟合。配准与地标来源要可复查。

“完全水平/垂直”作为指定直段目标，不承诺采样噪声为零。验收容差应在对应分辨率、实物结构和用户认可样例中确定；未经校准不得发明全库统一的像素/角度阈值，也不以阈值擦边掩盖肉眼可见歪斜。

### 4.3 滚边、筋、曲线和高清边缘

- 轮廓正确、曲线顺、边缘清晰是三个检查项。滚边中段不能凹成波浪，也不能为了拉直把细筋修成厚管；宽度和亮暗层次要与原款及已认可参照相符。
- 直线与圆角的交接方向应连续，弯曲程度渐变；避免接缝台阶、反向小钩、尖刺和一截突然变粗。左右只有在对应视角/设计下才比较，不要求完全镜像。
- 100%沿顶部、两侧、四角及五金连接逐段检查：阶梯锯齿、白晕、黑描边、双边、羽化漏白、插值尖刺、拼贴断层。平滑仅针对该边界的窄过渡；不能全包模糊后称“修锯齿”，也不能抹掉拉链齿与针脚。
- 重采样可用合理的高质量插值和边界抗锯齿；不要反复放大/锐化。插值放大不等于恢复真实细节，生成毛孔更不等于原材质。
- 若使用生成局部作供体，只能在已授权的局部重绘范围内采用，注明哪些区域不是原像素；材料主体/铭牌/连接仍用正确底图保护。合成后查供体蒙版边界的漏白、旧边残留、重复线、色阶和纹理接续，不以“只用了边缘”豁免验收。

### 4.4 颜色、明暗、材质

先诊断，再改参数：

| 现象 | 应区分的原因 | 正确方向 |
|---|---|---|
| 辅图彩色面片发灰、不够鲜艳 | 色度不足、曝光偏高、对比低、白平衡或不同色款 | 同款同色对应面片比较；按原因调色/中间调/对比，不拉低合格主图迁就坏图 |
| 黑包正面细节看不清 | 暗部压死、曝光不足、反光方向 | 保留黑位，适度提中暗调与层次；不是给黑色加饱和度 |
| 局部过亮、油亮、金属刺眼 | 正常反射 vs 遮蔽细节的异常高光、剪白 | 局部压高光，保留真实光泽；剪白且无源细节就不声称找回皮纹 |
| 整包变“AI皮” | 细纹变粗、纹路规整重复、磨皮、假锐化、材质被替换 | 撤回不可靠候选，优先同款同色原拍或原像素；不铺通用皮纹/噪声 |
| 局部贴材质不自然 | 源区域/方向/尺度/光照不匹配 | 先对齐真实地标与纹理尺度，只恢复获准区域；禁止拿相似但不同产品作材料证据 |

同尺度看原拍与候选的纹理方向、大小、不规则性、针脚、光泽。颜色统计可用对应皮面区域的明度/色度分布，排除背景、金属、阴影；全图直方图不能证明同色。均匀调色也须保护不同色拼片、白纸、铭牌、功能文字与阴影。

原像素局部几何仍可能拉长皮纹、压扁金属或字形；“蒙版外没改”不证明蒙版内正确。适度减大皱不消灭真实浅皱；空包支撑不足只修证实的塌陷，不鼓成气球或磨成硬壳。

### 4.5 背景、卡窗与阴影

- 纯白要求作用于**已确认的外部背景**。检查原照片矩形内部、产品外沿周边和真实穿透空隙，不能只测四角或新增白边。白皮、展示卡、窗膜、金属高光、边缘抗锯齿与阴影另作保护。
- 内框纸面“不够白”是内部对象问题，不用外部抠图规则一键掏空；保留纸边、窗膜/层深、原有功能字及其真实呈现。
- 自然阴影须服从包底落点、原光向与体积：接触处有贴地过渡，向外逐渐减淡，无分离灰椭圆、双影、硬灰框、过黑晕圈或一段凭空漂浮。包体移动/缩放后阴影同步，不保留旧底影。
- 区分“没有阴影”和“已有错误阴影”。项目可能容许仅缺阴影暂不动；悬浮、重影或漏处理的旧阴影是另一缺陷，不套用该例外。其他问题需修时，按本轮要求一并处理阴影。
- 最后重查纯白边界、透明度处理和实际文件模式；提示词中的尺寸/纯白不算测量证据。

### 4.6 文字、五金、包装与带路

- 先分类再去字：铭牌、圆形标识、拉片、皮面压印、功能卡不混为一类。许可字只在对应项目/对象有效；最新单图覆盖旧规则。保字不仅是“没删除”，还包括没有在几何变形中扭曲或重新拼写。
- 自然匿名保留金属实体、反光与固定方式，不用马赛克、纯灰块、糊字残影或伪文字。扶正/移动铭牌单独处理，不能带着附近皮面整块拉歪。
- 误删文字只从可信源恢复，不凭OCR猜测重打。原字形和真实材质要保留，功能压印不变成白色印刷。
- 扎带/纸套/拍摄细线与真实带、链、功能拉绳、皮样附件分开。去包装不造成断带、悬空五金或新生替代绑带。
- 闭合/卷起/截短背带必须有本图授权和结构参照；保留连接点、穿扣顺序、数量、带宽与遮挡。竖段扶直时横段随连接自然调整，不能两段独立变形造成断点。

### 4.7 视角：用可见变化避免“往左”歧义

任务单同时写 `目标可见面 + 侧面露出变化 + 顶面露出变化 + 禁止变化`。例如“右侧露出减少、正面增加”，比单写“向右转15°”更可验证；数字作为用户期望，不把单张2D变形冒充实测物理机位。

- 正面朝向不等于平视：仍可能有仰视/俯视。改上下位置不是改俯仰，平面旋转不是相机绕包旋转。
- 区分相机转动与包体转动；已明确期望的可见变化后，不重复问同一方向问题。
- 原像素有限透视只能改变已有可见面的投影，不能补造新侧面；若不能产生要求的可见差异，明确未达到，不以文件变了算成功。
- 多版选图绑定缩略序号与文件哈希；“第二张”是当次展示顺序，不是所有文件中v2。用户取消改角度后，从任务单移除旧角度指令。

## 5. 方法路由：什么问题用什么办法

| 状态/缺陷 | 首选方案（须在授权内） | 升级或停止条件 |
|---|---|---|
| 全部合格或明确接受轻微差异 | 保留，不为跑流程改图 | 新规则本身不撤销接受 |
| 内容合格，仅画布/占幅/居中 | 原像素补边、等比缩放、平移 | 实测主体变化与完整入画，不能只核画布 |
| 结构合格，仅色彩/亮度/对比 | 区域受控调色 | 剪白/压黑无信息先换源，不造纹理 |
| 点名加高/加宽/局部压缩 | 绑定基线的精确脚本变换 | 无相应授权不自行变形；检查字/五金及材料尺度 |
| 局部边框、筋、缝线、歪牌 | 获准原像素局部校正；必要时分离刚性部件 | 形变映射无折叠不等于视觉自然；出现尖刺/拉纹/假折痕就返修方法 |
| 局部去包装/自然匿名/局部补材 | 最小区域修补，真实源作指定供体 | 不可靠源、结构缺失先查图，不整包重画 |
| 视角或明显结构塌陷 | 匹配原拍优先；受限透视或授权局部生成 | 新面无证据、材质多次漂移时报告取舍，不能假称原像素恢复 |
| 锯齿、薄滚边、阴影 | 边界/曲线/接触区分别处理 | 只加模糊/锐化或灰椭圆不是替代方案 |

实际一次可组合数种方法，但步骤须可追溯，引用角色和保护项不能冲突。常用顺序：源身份与参照 → 结构/几何 → 必要局部材质/文字恢复 → 色调 → 占幅/居中 → 边界与落地阴影 → 最终画布和技术验收；有必要可调整，但不能最后一次缩放又留下分离旧影。

## 6. 对抗式审计：尝试推翻自己的“通过”

先看不带“已修好”标签的候选和参照，写观察，再对照修复目标。可用有权限的独立只读审计者；没有独立审计者就明确是自审，不把同一执行者二次阅读称为独立验收。审计发现不自动授予返修/上线权限。

| 反证问题 | 要看的证据 | 不接受的辩解 |
|---|---|---|
| 方图是否仍三种主体大小？ | 原画布整套、B高宽/重心 | W=H，所以一致 |
| 边是否只是端点平、中间仍弯？ | 多地标与完整边线、内外层 | 拟合斜率为零 |
| 外沿直但前袋、内筋、底边仍歪？ | 分层全景/局部 | 已运行透视校正 |
| 侧边直但拉链凸出、管筋过厚？ | 主体/突出层关系、参考厚度 | 轮廓框是长方形 |
| 皮纹是不是变了、字是不是被拉歪？ | 同尺度原拍、刚性部件局部 | 原像素脚本/蒙版外未改 |
| 锯齿消失是否只是模糊？ | 100%边界、齿列、针脚、实际展示 | 文件更大、更高清 |
| 阴影是否贴地而非灰椭圆？ | 下沿接触带与渐变 | 有阴影像素 |
| 白底是否只是四角/补边白？ | 原照片内外背景；卡纸保护 | 四角都是255 |
| 角度真的按所需方向变了吗？ | 正侧/顶面露出及地标 | 提示词写了15°/SHA不同 |
| 这项是否本就不该修？ | 该版本例外、功能文字、真实视角 | 通用规则说必须矩形/去字 |
| 发灰到底是明度、色度还是不同色？ | 对应材料面片、原色款 | 全图统一加饱和度 |
| 用户看到/选用/上线的是同一个文件吗？ | 图号→槽位→文件→哈希→实际引用 | 最新mtime/同名文件/API成功 |

**一票否决候选：** 错SKU/面/版本，指定问题仍明显存在，材质或结构变款，新增扭曲/断件/假文字，超出“只改”的范围，关键区域未看却记通过。保留原有有效版本，不把不合格候选混进合格交付。

**防误报的反向审计：** 拒绝候选前确认不是正常透视、真实不对称、自然圆角/细皱、不同色款、独立展示用途或用户已接受的差异。轻微不完美不自动授权“美化”。

## 7. 可执行任务单与修后证据

逐图至少记录：

```text
身份：SKU / 颜色 / 面 / 状态 / 图号别名 / media与槽位（如有）
底图：绝对路径 + SHA256 + 用户指定版本；参照分别用于哪些项目
当前决定：适用授权、只改项、接受例外、本轮次数与已用次数
问题ID：位置/结构层 → 可见现象 → 比较依据 → 影响
目标：哪条线向何处；哪个区域变化多少；包体而非整画布怎么变
保护：材质/字/刚性部件/连接/非目标区域；必要蒙版与锚点
路线：保留 / 脚本 / 局部编辑 / 源图不足；具体步骤，不泛写“优化”
输出：新候选路径；最终画布/文件规格读取项目约定
复验：问题ID逐项前后对照 + 非目标无倒退 + 全景 + 整套 + 100%局部
状态：内容、技术、用户接受、选用、发布分别记录；未知不记通过
```

提示词只展开本图所需模块，不把整章塞进生成请求。几何指令至少有**对象、方向、终点、参照、保护、验收**六项；禁止“保持所有颜色不变”同时“提鲜艳度”、“机位不变”同时“转正”等冲突。脚本指令说明基线/坐标/公式和作用域，不只写“放大一点”。

每次保存目标缺陷是否显著改善和新增问题；换语言、提示词、工具或子代理不重置次数。最新本轮精确次数优先于历史默认；到达上限或连续无进展的报告条件时停止该项并给具体替代路线，其他独立已授权项可继续。不要把数百个新文件当作进度。

若需要持久化决策/修复历史，使用已有的版本化追加事件契约，至少保留序号、时间、图像身份/哈希、动作、父版本与取代关系；当前表与页面由事件推导。未经需求不要再造另一套可变历史系统；原拍和原始证据不覆盖。

## 8. “完成”必须有相应层的证据

- **修复有效：** 每个点名问题有实际观察，不以技术统计或提示词自证。
- **整套协调：** 同一冻结清单里的全部现用图都看过；没抽到的不写成全部通过。记录总SKU/图数、检查/未检查数，问题图数与缺陷数分开，别名去重。
- **版本正确：** 一槽位一个当前选择。选了第2张就锁定那张；别把整包生成原稿当成后来保纹合成的最终稿。
- **上线真实：** 有对应授权后才执行，检查实际媒体、产品槽位、普通访客页面及所需衍生图。结果不明先读回，不盲重传。旧图重现先分辨选图/引用/重复视图/投影/缓存，不能未经证实就归因CDN。
- **清理准确：** 相似图仅是去重线索；不同颜色、可见面、开合和细节不能误删。同角度保留规则按当前项目执行；退出当前列表、媒体删除、本地删除、缓存消失分别核验，原拍受保护。

本章规则是否正确落地，可用[组合场景](09-coverage-and-scenarios.md)做任务单回放；文字演练通过不证明照片视觉合格或模型已获得新能力。
