# 客户/项目配置模板

此页用于记录约定，不默认授权任何编辑、重试、发布或删除。客户配置放在项目自己的受控文档中；公开Skill不收录客户名称、商品原图、实际SKU、生产媒体清单、内部路径或会话原文。下面留空项按任务确认，不以示例补成事实。

| 项目约定 | 应记录的内容 |
|---|---|
| 真实身份 | 已确认材料/功能、颜色、同款视图与主辅图角色；未知明确标注 |
| 唯一现用图 | 选图依据、确切版本、路径/哈希的本地记录位置；不得公开私有路径或签名URL |
| 白底/构图 | 是否RGB255、允许阴影/过渡、画布尺寸、同款占幅参照；例外逐图列出 |
| 铭牌/功能字 | 哪些区域匿名、哪些保字、哪些只扶正；不得使用笼统全图删字替代 |
| 包装/吊牌 | 哪些是可删的临时包装，哪些是真实承力结构；是否去细绳/特定牌片 |
| 视角/姿态 | 逐图需要保留、平视、轻俯、回转，还是仅缩放；不设全品类自动重拍 |
| 形态/材质 | 可修的大凹陷与允许保留的小皱，原拍/认可主图分别供什么证据 |
| 工具/授权 | 允许生成或脚本的范围，本轮次数、已用次数、未知结果，何时停止 |
| 验收例外 | 已认可的近白/原生尺寸/小残留，只属于对应图，不降级以后标准 |
| 交付与清理 | 用户选版、上线映射、受保护原片；发布与本地/线上删除分别授权 |

规则优先级不变：当前有效单图决定优先于项目偏好，项目偏好优先于通用模板。客户明确接受的图不会因为安装新版Skill而自动被重开修改。

跨客户复用时只迁移方法，不迁移某款五层带、某张压缩百分比、固定图片数量或历史剩余工作状态。
