# 定型后恢复原拍材质，不重新改款

用于轮廓已经认可、后续生成却改变皮纹，或原像素合成出现硬贴片、重复边、五金倒退的返修。它不是脚本授权，不承诺恢复不可见纹路；用户指定仅用图像编辑时，先遵守该工具边界。基本材料判断见[材质与部件](03-material-and-components.md)，完整检查见[第一性原理审计](11-first-principles-adversarial-audit.md)。

## 1. 动作先追溯，定型版本先锁定

- 对每个动作写明依据：当前用户要求、已确认项目规则，或明确标为待确认的建议。没有依据的动作不进入实际提示词或脚本。
- “扶正拉链”“增强拉片反光”不等于加长链轨、拉片或包带；“拉直侧边”不等于去掉底部圆角。“高清化”不授权重新生成皮纹。
- 锁定已认可版本的文件哈希、外轮廓、包底层数、提手/带根、拉链、铭牌和画布。后续只恢复被点名的材料或明暗，不把旧轮廓、旧尺寸要求再次带入。
- 原拍是指定面片的材质来源，不是默认新的整包底图。先区分定型底图、同款同色同面的材质供体、结构参考和用户标注；不惯例把全部参考图送去再生成。

## 2. 可见、对应、可配准，才谈恢复

优先用同一件产品、同色、同面的原拍，通过真实缝口、拉链端点和面片交界建立对应。先检查纹理方向、颗粒尺度、光照与形变；不同皮片不能仅因“都黑色”互换。

原拍的可见范围决定能恢复什么：

| 来源条件 | 可做什么 | 不能声称什么 |
|---|---|---|
| 对应皮片可见且能合理配准 | 获准后恢复该皮片内部的真实像素，保留定型结构 | 仅因用了原拍就称整图完全实拍 |
| 原拍提手遮住一条皮面 | 优先保留底图；若允许修补，可用同一皮片邻近可见像素并说明 | 找回了真实隐藏纹路 |
| 只有侧前面或不同色图 | 作已明确的结构/颜色参考，或说明证据不足 | 它证明了被遮住的背面材质 |
| 完全剪白、严重失焦且无可靠源 | 找更合适的原拍、曝光或说明限制 | 压暗、插值或生成毛孔恢复了真实细节 |

出现拉长颗粒、规则铺纹或不合理压缩时，退回配准与面片划分；不要用更强锐化或再生成掩盖。

## 3. 材质替换只进皮片内部

把编辑区域限制在获准皮片内部，避开外滚边、底边、缝线、拉链、拉片、铭牌、完整提手和其连接邻域。留出的窄过渡带按真实边界确定，不能套统一像素宽度。

1. 先在皮片内部验证真实纹理方向和尺度，再调合适的局部明暗。
2. 只在材料之间处理过渡；蒙版不跨五金、功能字或结构交界。不能把含五金和周围皮面的矩形裁块直接粘贴。
3. 若同时需要修五金或提手，那是单独动作：绑定原实体、固定点与局部授权，不混在“材质恢复”里重做。金属件不能随软皮一起变形。
4. 包底、牌位和拉链用一个明确的层归属，避免供体的旧底边、旧阴影或旧牌又叠到定型底图上。
5. 画布、提手高度、带宽和已通过圆角保持；需要整理尺寸时遵从当前单图约定，不默认再次扩大画布。

使用原拍像素也可能出现贴片、双边和假层次。“没有生成皮纹”只描述来源，不证明合成自然。更不能把合成结果再次送去整包生成，以“融合”名义重新换纹。

## 4. 光泽、鲜明度和金属，分区处理

皮面、织物、链齿与金属牌的反光不是同一个调整区。

- **皮面发白或过亮：** 有细节时局部减高光、协调中间调；保留正常反射和浅皱，不全包压成死黑或变哑光。
- **黑皮不鲜明：** 检查黑位、局部对比和中暗调可读性，不用加饱和度处理黑色；避免提亮后整面灰白。
- **彩色面片发灰：** 在同色对应面片上判断白平衡、色度与曝光，保护实际颜色；不把一种“鲜艳度”套给整包。
- **匿名铭牌：** 保留牌框、厚度及原有亮暗反射，只处理获准文字或牌位。均匀灰色填充、模糊磨砂不是金属光泽。
- **口金、拉片、链齿：** 保留真实亮面、暗面和边缘高光。优化皮面反光时必须排除它们，不能让金属一起失去光泽；不同金属不能擅自换镀色。
- 原为抛光/电镀的部件不能改成磨砂；原本拉丝/磨砂的部件也不能擅自改成镜面。“更有金属感”不授权改变表面工艺。

这里没有全图统一曝光、羽化、降噪或锐化参数。调整强度取决于确切底图、源信息和用户要求；数值不是通过标准。

## 5. 成对反证，不能只验蒙版外

每次看同一底图、对应原拍、候选的全景与同尺度100%局部，再看实际展示大小。至少检查：

| 要求改善 | 必须排除的倒退 |
|---|---|
| 材质更真实 | 规则铺纹、颗粒拉长、供体方向错误、皮片交界突变 |
| 包底修平 | 双层下巴、重复滚边、旧阴影和悬浮底边 |
| 铭牌或五金自然 | 双牌、矩形贴块、磨砂灰面、牌形或连接改变 |
| 侧边更直 | 硬尺状边、圆角消失、锯齿、厚管滚边 |
| 缝线水平 | 只改端点，中段仍波浪；行数和交叉关系改变 |
| 提手姿态合理 | 变长、变细、固定点移动、皮片粘到提手或擦出不真实白洞 |
| 减少皮面亮面 | 拉片和口金一起变暗，黑皮暗部压死 |

可对明确保护区检查像素和渲染元数据一致，但还要检查变化区及其邻接。保护区通过不能抵消贴片、材质错面或指定问题未修好。

交付写清：哪些皮片恢复了对应原拍像素，哪些区域仍沿用定型底图，哪些是邻近像素修补而非隐藏纹路恢复。用户认可确切版本后锁定选择，不因后续通用规范重新改轮廓或补做未要求的优化；发布与清理另按[资产管理](05-delivery-and-retention.md)核对。
